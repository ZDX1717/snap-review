# Zquiz · 期末周刷题

**Zquiz**（期末周刷题）是一个基于 Web 的纯前端刷题工具：把任意格式的题目粘贴进来就能刷。支持多格式题库导入、逐题边刷边学、套题模式模拟考试、错题自动归档。零依赖、零构建、无需注册，所有数据仅保存在本地浏览器。

**在线使用**：<https://zdx1717.github.io/zquiz/>（手机浏览器打开即可，建议"添加到主屏幕"当 App 用）

## 功能特点

- **多格式题目导入**：字段式、编号式、单行混排、判断题自动识别，无需事先整理格式；支持富文本粘贴（Word / PDF / 网页 / 微信复制）与 txt / docx 文件导入；文末集中答案表自动按题号回填
- **导入预览向导**：解析结果先预览再入库 —— 逐题勾选、直接修改题干和答案、自动查重跳过重复题、缺答案/选项不足等警告提示
- **两种作答模式**：
  - 逐题模式：每题立即出答案，作答时显示题目/选项解释，边刷边学
  - 套题模式：整组作答、可前后翻页修改、交卷后统一判分并逐题回顾（支持"只看错题"），可模拟考试
- **题型**：单选题、多选题、判断题
- **错题本闭环**：答错与未作答的题自动归档，按题库分组折叠查看；移出规则可配置（答对 1/2/3 次移出或关闭），答错清零重新计数
- **复习范围**：复习错题时按题库、题型勾选范围，精准刷薄弱点
- **收藏夹**：刷题时一键收藏重要题目（★），汇总成册、支持专项复习
- **题库编辑器**：题库可视化编辑 —— 题干/题型/选项/答案/解析逐题修改，支持增删题目与选项
- **多题库管理**：创建 / 重命名 / 编辑 / 删除 / 导入 / 导出 / 一键去重，刷题时可选单库或多库混合出题
- **数据本地存储**：刷新不丢失；题库可随时导出为 txt 备份迁移

## 快速上手

1. 打开在线地址；本地运行请先起一个静态服务（如 `python3 -m http.server`）再访问（ES Module 不支持 file:// 直开）
2. 进入「题库管理」，把题目粘贴到"粘贴导入"框（或选择 txt / docx 文件）→ 点击"解析并预览" → 检查无误后选择题库导入
3. 进入「开始刷题」，选择作答方式（逐题 / 套题）和题型，开始刷题
4. 做错或没答的题自动进入「错题本」，考前来一轮错题回顾

## 题库格式

题库导入支持**多种常见格式的自动识别**，无需事先整理：

| 格式 | 示例 | 来源场景 |
|---|---|---|
| 字段式 | `题目：` `A：` `答案：` | 手工整理的题库文件 |
| 编号式 | `1. 题干` / `A. 选项` / `答案：B` | 题库软件导出、Word 文档 |
| 单行混排 | `1. 题干 A.xx B.xx C.xx D.xx 答案：B` | 网页/微信复制 |
| 判断题 | 答案为 `对/错/√/×/正确/错误` | 各类题库 |

**粘贴导入**：在「题库管理」页把 Word / PDF / 网页 / 微信里的题目复制粘贴到文本框（富文本会按段落和表格结构读取），点击"解析并预览"。PDF 内的题目建议先复制文字再粘贴。

**文件导入**：在「导入题库文件」选择 `.txt` 或 `.docx`（docx 在浏览器本地解析，不上传服务器）。老版二进制 `.doc` 暂不支持，请先另存为 `.docx` 或复制文字粘贴。

**导入预览**：解析结果先进入预览向导，可逐题勾选、修改题干和答案、查看警告（缺答案/选项不足/与现有题库重复），确认后才写入题库。

### 答案的写法（自动识别）

- **行内/整行**：`答案：B`；多选连写 `答案：ABD`；判断题 `答案：对` / `答案：错`（自动配"A 正确 / B 错误"选项）
- **题末括号内嵌**：`……构成故意杀人罪。（B）`、`（ABD）`、`（x ）`（判断题标记 ×）
- **判断语境惯例**：同一批材料里若存在 `（x）`/`（√）` 判卷痕迹（"只标错、不标对"的判卷惯例），未标记的空括号题自动视为**对**；显式 `判断题：` 前缀的单题同样兜底。有选项的选择题与无判卷痕迹的批次不受影响
- **没有答案**：预览中标"缺答案"警告；确认导入时会明确提示"N 题因缺答案未导入"，可回预览补填答案后重新导入。括号内是"?"等非答案字符的题如实保留缺答案

### 集中答案表（文末）

答案不必逐题内嵌，支持文档末尾的集中答案区，按题号自动回填：

```
参考答案：
1.B
2.【A】
3-5 BBA
```

也支持单行多对（`答案：1.B 2.A 3.D`）与对错判卷表（`1.对 2.错`）。两个前提：**答案区在文档末尾**；**题号与题目编号对应**。

### 容错能力

- 选项布局：双行选项（第二行 `C.xx D.yy`）、全/半角逗号与顿号分隔（`C,xx D，yy`）、空格分隔（`A 盗窃罪`）、选项折行自动归并不污染题干
- 噪音清理：空答题槽括号 `（）` 自动清除；答案与选项大小写、分隔符写法差异不影响判分
- 查重：按"题干 + 选项"指纹，批内与目标题库均自动跳过重复

### 字段式格式说明

```
# 题目标题（可选）
题目：题目内容
A：选项A内容
B：选项B内容
C：选项C内容
D：选项D内容
答案：A
```

可选字段：

- `题目解释：` - 题目的解释说明
- `解析：` - 答案的详细解释
- `A解释：` `B解释：`… - 各选项的解释
- `类型：` - 单选/多选/判断（可省略，系统按答案自动判断）

分隔符灵活：`题目：`/`题目:`/`题目 ` 均可，选项支持 `A：` `A.` `A、` `A)` 等，答案大小写不敏感；多选答案 `CA`、`A、C` 等写法都能正确判分。

### 多选题示例

```
# 多选题示例
题目：以下哪些是编程语言？
A：Python
B：Java
C：C++
D：HTML
答案：ABC
解析：Python、Java和C++都是编程语言，HTML是标记语言
```

### 完整示例（含解释与解析）

```
# 单选题1
题目："祸兮福之所倚，福兮祸之所伏"体现了（）
题目解释：灾祸中潜藏着福气的可能，福气里也隐含着灾祸的隐患。
A：矛盾的同一性
A解释：矛盾双方相互依存、相互贯通，能够在一定条件下相互转化。
B：矛盾的斗争性
B解释：矛盾双方相互排斥、相互对立的属性。
C：矛盾的特殊性
C解释：不同事物的矛盾具有各自独特的特点。
D：矛盾的普遍性
D解释：矛盾存在于一切事物中，贯穿事物发展全过程。
答案：A
解析：题干中福与祸相互依存、相互转化，完全契合矛盾同一性的定义。
类型：单选
```

## 文件说明

```
index.html            主页面（首页介绍 / 刷题 / 错题本 / 收藏夹 / 题库管理）
styles.css            样式
src/
  main.js             应用装配入口：事件绑定 + 页面调度
  state.js            共享状态（全站唯一可变数据容器）
  parser.js           纯函数解析核心（多格式解析 / 答案规范化 / 判分指纹）
  storage.js          存储层（唯一触碰 localStorage 的模块，含损坏降级）
  quiz.js             刷题（逐题 / 套题 / 判分 / 逐题回顾 / 复习范围）
  errorbook.js        错题闭环与错题本渲染
  favorites.js        收藏夹
  bank.js             题库管理 / 导入预览 / 题库编辑器 / 导出
  docx.js             docx 文件抽取（零依赖 zip + XML → 纯文本，供文件导入）
  dom.js              通用 DOM 工具（模态框开关 / 文件下载）
tests/                Node 内置 test runner 的回归套件（28 组用例）
.github/workflows/    CI：push/PR 自动回归
```

模块依赖方向：`main → 业务模块 → parser/storage/state`，`parser/state` 零依赖，禁止反向引用。

## 数据与隐私

- 所有数据（题库、错题本）仅保存在浏览器的 LocalStorage 中，**不上传任何服务器**
- 清除浏览器数据会连同题库一起清掉 —— 重要题库请定期用「导出题库」备份
- 换设备 / 换浏览器时，先导出、在新设备导入即可完成迁移

## 技术栈

- HTML5 / CSS3 / 原生 JavaScript (ES6+)，运行时零依赖、零构建
- ES Modules 多模块架构（纯核 parser + 存储层 + 业务模块）
- Node 内置 test runner + GitHub Actions CI
- LocalStorage API；GitHub Pages 托管

## 注意事项

- 题库文件建议使用 UTF-8 编码
- 每道题需包含题干和答案；解释、解析等字段可选
- PDF 内的题目建议先复制文字再粘贴导入；扫描版（图片）暂不支持
- 浏览器隐私模式或清理缓存可能清空 LocalStorage 数据，请及时备份

## 浏览器兼容性

支持所有现代浏览器，包括 Chrome、Firefox、Safari 和 Edge。
